Ledgermint: High-Performance Blockchain Core in Golang
A lightweight, modular blockchain implementation focusing on cryptographic integrity, asymmetric key security, and state-based ledger transitions. This project serves as a functional demonstration of blockchain infrastructure fundamentals using Go.

🚀 Key Features & Skills Demonstrated
Cryptographic Hashing: Implementation of SHA-256 for block immutability and chain integrity.

Identity & Wallets: ECDSA (Elliptic Curve Digital Signature Algorithm) on the secp256k1 curve for secure wallet generation.

Digital Signatures: Native transaction signing and verification to ensure non-repudiation and prevent unauthorized state changes.

State Management: An account-based model (similar to Ethereum architecture) to track balances and prevent double-spending.

Transaction Validation: A rigorous validation engine that checks both cryptographic signatures and sufficient balance before committing to the ledger.

Cryptography: crypto/sha256, github.com/ethereum/go-ethereum/crypto (secp256k1)

Encoding: hexutil, gob

💻 Getting Started
Prerequisites

Bash

🔐 Cryptographic Implementation Details
Wallet Derivation
The wallet uses the Elliptic Curve Digital Signature Algorithm.

A Private Key is generated using a cryptographically secure random number generator.

The Public Key is derived.

The Wallet Address is generated by taking the Keccak-256 hash of the public key (Ethereum standard).

Transaction Lifecycle
Creation: A transaction is initialized with a Sender, Recipient, and Amount.

Hashing: A unique ID is created by hashing the transaction data.

Signing: The Sender signs the ID using their Private Key.

Verification: The Network verifies the signature using the Sender's Public Key before updating the World State.
